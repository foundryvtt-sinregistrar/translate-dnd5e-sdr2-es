English

Play D&D 5e SRD 2024 compendiums in Spanish. This unofficial community module provides Spanish translations of the D&D 5e SRD 5.2.1 compendium content through Babele. It includes structured translation mappings, semantic normalization, and targeted runtime fixes.

What's included

  • 10 SRD compendium mapping files covering actors, classes, rules content, effects, equipment, feats, monster features, origins, spells, and tables.
  • Automatic registration for Spanish (es) and regional variants.
  • Support for structured activities, effects, and character-advancement data.
  • Validation on 2,453 documents across 10 compendiums (September 2026); this is not a comprehensive linguistic or functional audit.

Requirements and installation

Foundry VTT 14.367+ · D&D 5e 6.0.0+ · Babele 2.9.1+. Verified with Foundry 14.368, D&D 5e 6.0.3, and Babele 2.9.1.

  1. Install the D&D 5e game system and Babele.
  2. Install this translation from Foundry's module browser or via the manifest URL.
  3. Enable Babele and this translation in a D&D 5e world.
  4. Select Spanish (es), reload the world, and open an SRD compendium.

Installation manifest: module.json

Español

Juega con los compendios de D&D 5e SRD 2024 en español. Este módulo comunitario no oficial traduce al español el contenido de los compendios D&D 5e SRD 5.2.1 mediante Babele. Incorpora mapeos estructurados, normalización semántica y correcciones de ejecución específicas.

Contenido incluido

  • 10 archivos de mapeo de compendios SRD: actores, clases, reglas, efectos, equipo, dotes, rasgos de monstruos, orígenes, conjuros y tablas.
  • Registro automático para español (es) y sus variantes regionales.
  • Soporte para actividades, efectos y avances de personaje estructurados.
  • Comprobación sobre 2.453 documentos en 10 compendios (septiembre de 2026); no supone una auditoría lingüística ni funcional exhaustiva.

Requisitos e instalación

Foundry VTT 14.367+ · D&D 5e 6.0.0+ · Babele 2.9.1+. Verificado con Foundry 14.368, D&D 5e 6.0.3 y Babele 2.9.1.

  1. Instala el sistema D&D 5e y Babele.
  2. Instala esta traducción desde el gestor de módulos de Foundry o mediante el manifiesto.
  3. Activa Babele y esta traducción en un mundo de D&D 5e.
  4. Selecciona Español (es), recarga el mundo y abre un compendio SRD.

Manifiesto de instalación: module.json
