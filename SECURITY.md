# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.14.x  | :white_check_mark: |
| 1.13.x  | :x: |
| < 1.13  | :x: |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report them privately by contacting the repository maintainers through GitHub. Include:

- A description of the issue and its potential impact.
- Steps to reproduce it.
- Affected module, Foundry VTT, dnd5e, and Babele versions.
- Any proposed mitigation, if available.

We will acknowledge the report within 7 days and provide status updates as the issue is investigated. If accepted, we will work on a fix and coordinate disclosure in a future release. If declined, we will explain why when possible.
